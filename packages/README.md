# Pacotes compartilhados

Espaço para contratos e bibliotecas com consumidores em mais de um workspace. Nenhum pacote compartilhado foi extraído nesta etapa.

Cada pacote futuro deve ter um `package.json`, API pública explícita e dependências próprias. Não inclua tokens, conexões privilegiadas, componentes privados do painel ou regras de autorização que eliminem o escopo da aplicação consumidora.
